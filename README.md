### 🏆 Featured Projects

#### 🧠 [Automated Essay Scoring](https://github.com/Prince-410/Automated-Essay-Scoring)

An advanced deep learning system designed to automatically grade student essays. Utilizes state-of-the-art Natural Language Processing (NLP) models, including DeBERTa and BERT, along with custom feature engineering.

- **Result:** Achieved a **Quadratic Weighted Kappa (QWK) score of 0.926** (92.6% agreement with human graders).
- **Tech:** Python, PyTorch, Transformers, Scikit-learn, NLP.

#### 🍔 [FoodieDash — Online Food Ordering System](https://github.com/Prince-410/Online-Food-Ordering-System)

A full-stack food delivery platform with glassmorphism UI, real-time order tracking, JWT authentication, admin dashboard, cart management, and role-based access control.

- **Result:** Built a premium responsive dark theme application.
- **Tech:** React.js, Node.js, MongoDB, Express.js, TypeScript.

#### 💻 [Laptop Price Predictor](https://github.com/Prince-410/laptop-price-predictor)

An ML-powered application that predicts laptop prices based on specifications. Features a modern glassmorphism UI, FastAPI backend, and trained ML model deployed for real-time inference.

- **Tech:** Python, Scikit-learn, FastAPI, HTML/CSS.

#### 🏥 [ML Disease Prediction System](https://github.com/Prince-410)

End-to-end ML pipeline with data preprocessing, feature engineering, and model training achieving 94% accuracy. Deployed a prediction API via Flask on GCP handling 200+ daily inference requests.

- **Tech:** Python, Scikit-learn, Flask, GCP, Pandas.
